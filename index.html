Smart glasses that remember for him — and turn the forgetting into a measurement.

The glasses speak into his ear: who just walked in, the shared memory that makes the greeting real, the 1pm pill. The dashboard watches one thing nobody else measures — how much help he needed, and whether that is changing.

Never used this before? Do these three things, in order.

What is real and what is simulated

Say this out loud on stage. Judges reward it.
ComponentStatusNote
Face detection & 128-d embeddingReal face-api.js, TinyFaceDetector + FaceRecognitionNet, running entirely in-browser. Weights vendored locally (6.5 MB) — no CDN, no network at run time.
Enrolment-only matchingReal Euclidean distance against consented descriptors, threshold 0.52. Non-enrolled descriptors go out of scope with the frame — see the comment block in js/vision.js.
“Someone is here”Real Below threshold we never guess. A wrong name is worse than no name.
Spoken prompts, EN + MandarinReal Web Speech API, rate 0.82 for presbycusis. Voice availability depends on the OS.
Vanishing-cue ladderReal Full state machine: 3 unaided retrievals advance, 2 failures regress, interval ×1.6 / ÷2. Persisted per person.
Retrieval detectionReal He says the name; browser speech recognition catches it. Manual G/N keys always work as a fallback so the demo cannot fail.
Cognitive Trajectory IndexReal maths, seeded history Live sub-scores are computed from this session’s actual events. Weeks 1–10 are seeded and labelled as seeded in the UI. Weights are a first pass, not a validated instrument.
Wear-time & idle power-downReal, proxied Driven by face-detection activity rather than an IMU, because a browser has no accelerometer here.
Scheduler — briefing, medication, appointments, reminiscenceReal js/schedule.js. Fires on real clock time, once per key per day so a reload cannot re-nag. Medication re-prompts once after 15 min, then escalates to the caregiver — once, not repeatedly.
Consent gateReal Recognition will not run without recorded consent and active assent. Reminders are a separate purpose and keep working — that is the PDPA Purpose Limitation obligation in code, not in a policy document.
Data export, erasure, audit trailReal Export downloads an actual file. Erasure actually destroys descriptors. The audit log is append-only.
Recorded family voiceReal MediaRecorder, stored on-device, played instead of TTS when present. Falls back silently.
Place promptsReal, manually triggered Fires from buttons in the glasses view. In the product these are GPS geofences; a browser tab is the wrong place to prove that.
Presbycusis EQ, whisper modeNot simulated Audiogram-shaped EQ and consonant emphasis are firmware-level. The browser exposes rate and pitch only.
On-glasses executionRoadmap Eyewear 2 has no camera; AI Glasses is China-only with no public SDK. Phase 1 pairs Eyewear 2 audio with the phone camera — which is what this prototype models.
Huawei Cloud MaaSCoded, not keyed Prompt generation and the weekly summary are written against the Singapore-region endpoint in js/maas.js. Falls back to local templates without credentials.
Why this runs offline. Every model weight, script and stylesheet is on disk. A competition venue’s wifi cannot break the demo, and no face data leaves the machine — which is the same argument as the privacy slide, demonstrated rather than asserted.
